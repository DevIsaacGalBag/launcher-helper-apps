Funciones

Qué hace cada vez que prendés la compu

Todo pasa en los primeros segundos, sin que tengas que abrir nada a mano.

  • 1Te saluda por voz ("Buenos días señor...")
  • 2Te dice el día y la fecha
  • 3Te cuenta el clima de tu ciudad, detectada sola por IP
  • 4Abre Spotify en la canción que elijas
  • 5Abre las apps que actives en el panel (Discord, el navegador, VSCode...)
Cómo funciona

Tres pasos y listo

  1. Descargá el programa de tu sistema Un solo archivo, sin instalador. Windows o Linux, según lo que uses.
  2. Abrí el panel y configurá lo tuyo Tu nombre, la voz, el link de tu canción de Spotify, y qué apps se abren.
  3. Activá "Iniciar con la compu" y guardá A partir de ahí, Jarvis se ejecuta solo cada vez que prendés el equipo.

Configuración

Un panel, no un archivo de texto

Nada de editar JSON a mano: elegís todo con switches y menús desplegables.

  • ✓Tu nombre, para que el saludo sea personal
  • ✓Elegís la voz entre varios acentos en español
  • ✓Pegás el link de tu canción tal cual lo copiás de Spotify
  • ✓Buscás entre tus apps instaladas, como en el menú de aplicaciones
Requisitos

Antes de descargar

  • ✓ Windows 10/11 o Linux (con entorno de escritorio: GNOME, KDE, XFCE, etc.)
  • ✓ Conexión a internet (se usa para la voz y el clima)
  • ✓ No hace falta tener Python instalado — el ejecutable ya lo trae todo
Descarga

Llevátelo

Un solo archivo portable — no instala nada en tu sistema hasta que vos actives el inicio automático.

⊞ Descargar para Windows.exe · no requiere instalación 🐧 Descargar para Linuxbinario · marcar como ejecutable

Windows: puede aparecer una advertencia de SmartScreen porque el .exe no está firmado digitalmente — tocá "Más información" → "Ejecutar de todas formas". No hay que instalar nada ni ejecutar como administrador: se abre directo el panel de configuración.

Linux: si hace falta, dale permiso de ejecución antes de abrirlo: chmod +x Jarvis-Linux.
